## 📌 Featured Projects

### 🚔 [ParkSentinel](https://github.com/sreejeetaroy2005-svg/parkSenitel)
**AI-driven parking hotspot intelligence for Bengaluru Traffic Police.**
- Scores locations with a deterministic **Congestion Impact Score** (volume, severity, junction proximity, peak-hour weighting), so every ranking can be audited
- Validates hotspots with **DBSCAN** spatial clustering and flags anomalies with **IsolationForest**
- Gives officers enforcement priorities on an interactive map dashboard, covering **68 police stations**

`Python` `scikit-learn` `H3` `FastAPI` `React` `TypeScript`

### 🌫️ [AQI·INTEL (AirLens)](https://github.com/sreejeetaroy2005-svg/AirLens)
**Multi-city air quality forecasting and enforcement recommendations.**
- A **6-agent pipeline** ingests real **CPCB** data and bins it into **H3 hex grids**
- Forecasts AQI **24-72 hours ahead** with per-city **LightGBM** models, a **~19% RMSE improvement** over baseline
- Attributes pollution sources using OSM data and ranks enforcement zones by a composite urgency score, with **LLM-generated, evidence-backed explanations**

`Python` `FastAPI` `LightGBM` `React` `Deck.gl` `H3`

### 🏨 [Vanguard](https://github.com/sreejeetaroy2005-svg/Vanguard-total) · [🔗 Live Demo](https://vanguard-total-h1uq.vercel.app/)
**AI-powered hotel emergency evacuation system.**
- **Hazard-aware Dijkstra** pathfinding that routes guests around danger and respects accessibility needs
- **Dual-AI classification pipeline** (Gemini cloud with a local fallback), so it keeps working when connectivity doesn't
- **YOLOv8** detects hazards from CCTV, and **Server-Sent Events** push live route updates to guests

`Java` `React` `Python` `Firebase`

### ⚖️ [Judgment2Action](https://github.com/sreejeetaroy2005-svg/Judgement2Action) · [🔗 Live Demo](https://judgement2-action.vercel.app)
**Turns court judgments into actionable, risk-scored plans.**
- Custom **Legal RAG engine** built on **70+ years of Supreme Court judgments**
- Uses **Gemini 1.5 Flash** to extract obligations and produce risk-scored action plans

`TypeScript` `FastAPI` `ChromaDB` `React`

### 🚨 [RoadSOS](https://github.com/sreejeetaroy2005-svg/RoadSOS)
**Offline-first PWA for road accident emergencies.**
- Covers **8 countries** with **116+ emergency contacts**, live GPS mapping and voice commands
- Real **background sync via IndexedDB** when connectivity returns, so it works where networks don't

`JavaScript` `Node.js` `Firebase` `Leaflet.js`

### ♻️ [TraceFlow](https://github.com/sreejeetaroy2005-svg/traceflow_app) · [🔗 Live Demo](https://traceflow-app-s6n5.vercel.app/)
**Blockchain-powered, AI-assisted waste traceability for India's informal recycling ecosystem.**
- Role-based dashboards and live batch tracking from collection to recycling
- Custom **Canvas-drawn analytics** with no charting library

`Node.js` `PostgreSQL` `JWT` `Vanilla JS`
